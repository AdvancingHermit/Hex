# Hex Arena

This is a Hex program to play Hex against Algorithms, Online Players, or just Locally.

The program can be compiled and run with Java 18, using IntelliJ, as a JavaFX project.

The DQN algorithm however only works on x86_64 and not on arm. The rest of the program should still work, but the Deep Java Library seems to have issues with arm devices.

There is only included a compiled version for windows devices running on x86_64.
